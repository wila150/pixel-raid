# 05 英雄要不要留＋角色介面調整（11/07，遊戲企劃 game；使用者問的）

（04 保留給「改招三選一」）

## 1. 問題

### 1-1 英雄
現在（build.js `HEROES`）：建立角色時三選一，綁定角色、拆不掉。
| 英雄 | 保命技（V） | 核心被動 |
|---|---|---|
| 時空浪人 | 回到 3 秒前位置和血量（30 秒） | 切武器後下一招段數 ×2 |
| 劇毒魔女 | 4 秒免疫物理（40 秒） | 法術武器傷害全變毒 |
| 吸血鬼 | 5 秒無敵（60 秒） | 吸血 3%、殺怪回 1% |

另外有「傳授寶石」：別的角色練到二轉，可以把他的被動插在佩上（`it.link`）。

問題：
1. **跟遊戲核心原則打架**：使用者定過「沒有職業，武器決定招式、自由搭配」。英雄是一個「建角色時就鎖死、拆不掉」的職業，剛好相反。
2. **新手在最不懂的時候做最重要的選擇**：建立角色第一分鐘就要選，選錯只能重練一隻 Lv.1。
3. **被動只對特定玩法有用**：魔女只對法杖／扇有意義，拿劍的魔女等於沒有被動；浪人要一直切武器才有用。這不是「選英雄」，是「選流派」，應該跟著裝備走。
4. **跟其他系統重複**：吸血鬼吸血＝嗜血寶石＋吸血詞綴；魔女毒＝企劃 02 的萬毒蟾衣；三個系統在做同一件事。
5. **傳授寶石要練第二、三隻角色到 Lv.30 才拿得到**，等於逼玩家重練，大部分人不會做，系統白做。

但有一個東西**很值得留：保命技**。手機上一顆「快死了按一下」的按鈕（`#wbar` 最右邊那顆）很重要，現在三種保命技的感覺也都不一樣、都很好玩。

### 1-2 角色畫面
現在（world.js `renderAP`＋build.js 包一層＋`fashionHtml`）一個視窗從上到下塞了：基本資料、四圍配點、詳細數值、招式說明、暱稱、時裝、英雄核心、轉職、角色列表。問題：
1. **太長**：手機要捲很久才看到轉職按鈕，最常用的「配點」和最少用的「時裝」擠在一起。
2. **跟行囊長得不一樣**：行囊是 v3.0 的毛玻璃覆蓋層 `#ov`（左中右 3:4:3），角色還是舊的 `screenEl` 面板，兩個視窗像兩個遊戲。
3. **配點重複**：行囊左欄已經有 ＋／＋5（`apHtml`），角色畫面又一份。
4. **數值看不懂**：「法術壓制 12%」「能量護盾 340」沒有說明，玩家不知道該不該追。
5. **沒有角色本人**：整頁都是字，看不到自己穿成什麼樣子（行囊有剪影，角色畫面反而沒有）。

## 2. 提案

### 2-1 英雄：拿掉「選英雄」，保留保命技，被動拆給裝備／心法
- **建立角色只剩三步**：取名 → 選初始武器 → 選外觀（少一個看不懂的選擇，新手更快進遊戲）。
- **保命技變成「護身法術」，可以自由換**：
  - 一開始送「時間回溯」（最直覺），一轉解鎖「化身霧氣」，二轉解鎖「血霧無敵」。
  - 在安全營地隨時換（角色畫面「修行」分頁）。以後要加新的保命技（縮地、金鐘罩…）也放這裡，01 提的「心法主動」就是這一格，**不用加新按鈕**。
- **三個核心被動改成可以撿、可以換的東西**：
  - 浪人「切武器段數 ×2」→ 傳說佩「時之沙漏」（剛好配合武器組 1/2/3）。
  - 魔女「法術變毒」→ 併進企劃 02 的萬毒蟾衣（或做成輔助寶石「毒化」），扇／法杖流派才會去追。
  - 吸血鬼「殺怪回 1%」→ 心法大節點（01 提案 6「狂心」那種二選一）。
- **傳授寶石整套拿掉**（被動都變成裝備了，不需要靠練別的角色）。
- **多角色還是留著**：理由變成「想同時養兩套不同的轉職／配點」，不用為了拿傳授寶石重練。
- **舊存檔**：原本選的英雄 → 那個保命技直接解鎖，其他照轉職解鎖；原本的被動送一件對應的傳說（浪人→時之沙漏、魔女→萬毒蟾衣、吸血鬼→送一次免費心法節點），插著的傳授寶石拆掉變碎屑。玩家不會覺得被拿走東西。

### 2-2 角色畫面：改成覆蓋層、分頁
改用跟行囊一樣的 `#ov`（左中右 3:4:3，毛玻璃，點空白關），分 3 個分頁：

```
┌────────────┬──────────────────────┬──────────────┐
│  [角色大圖]  │ [屬性] [修行] [外觀]                  │  數值說明      │
│  穿什麼就畫  │                                      │              │
│  什麼        │ 屬性：STR AGI INT VIT  ＋ ＋5        │ 點中間任一行，  │
│  暱稱 Lv.48 │   能力點 3   重新配點                 │ 這裡顯示「這是  │
│  二轉・御劍  │   ── 主要 ──                          │ 什麼、怎麼提高、│
│  戰力 12,340│   攻擊 爆擊 攻速 生命 移速            │ 你現在跟同等級  │
│  經驗 ▓▓▓░ │   ── 防禦 ──（摺疊）                   │ 平均比如何」    │
│            │   護甲 閃避 壓制 抗性 護盾 吸血        │              │
│ [切換角色]   │                                      │              │
└────────────┴──────────────────────┴──────────────┘
```
- **左欄（永遠在）**：角色大圖（`heroImg`，跟著裝備和時裝變）、名字、等級、轉職、戰力、經驗條；最下面「切換角色」小按鈕（點了才展開角色列表，平常不佔位）。
- **屬性分頁（預設）**：配點＋數值，數值分「主要」（5 項）和「防禦」（摺疊）。點任何一行，右欄說明那個數值（例：「法術壓制：被子彈打中時有這個機率傷害減半。靠 AGI 和後綴詞綴提高」）。
- **修行分頁**：轉職路線（4 格，下一轉有進度條和「Lv.70 可以三轉」）、護身法術選擇（2-1）、以後的心法大節點也放這裡。
- **外觀分頁**：暱稱、時裝（從主頁面搬出來，最少用的東西放最後）。
- 行囊左欄的配點保留（方便），角色畫面這份是完整版。
- 手機直向：左欄縮成頂部一條（小頭像＋名字＋等級＋戰力），分頁在下面，右欄說明改成點了才浮出來。
- 右上快捷列的紅點規則不變（有能力點／可轉職）。

## 3. 玩家體驗
- 新手：建角色更快，不用一進來就做看不懂的決定；保命技隨轉職一個個解鎖，每次轉職多一個「新玩具」。
- 老手：想玩毒就去刷萬毒蟾衣，想玩切武器就去找沙漏 → 「流派跟著裝備走」，跟 03 的流派卡接得起來。
- 角色畫面打開一眼看到自己長怎樣、有沒有點數、能不能轉職，不用捲。

## 4. 要改的檔案
- `js/build.js`：`HEROES` 改名 `SAVES`（只剩保命技），`heroKey()` → `save.w.sv`（選中的保命技）＋解鎖判斷看 `jobLv()`；`heroHas` 改看裝備 mod（`B.uq.hourglass` 等）；拿掉 renderAP 包裝裡的英雄／傳授段落；舊存檔轉換（`migHero`，用 `w.hv=1` 標記）。
- `js/inv.js`：拿掉傳授插槽 `supslot`/`data-link`；角色覆蓋層 `renderChar`（新）用 `ovOpen`。
- `js/world.js`：`renderAP` 換成呼叫新的覆蓋層；`hurtW` 的 mistT／invT 照留（保命技效果不變）。
- `js/art.js`：`renderCreate` 拿掉英雄那一段。
- `js/equip.js`：`UNIQUES` 加時之沙漏（佩，mod `lbDouble`）。
- `style.css`：角色覆蓋層、分頁、數值說明。
- `index.html` 全部 `?v=`。

## 5. 風險
- 拿掉「選英雄」是玩家看得到的改變 → **要先問使用者**（builder 的原則：刪玩家看得到的東西先問）。
- 舊玩家可能有插傳授寶石的佩 → 轉換時拆掉補償碎屑，跳一次說明。
- 角色畫面搬到覆蓋層：要確認連線不暫停（`liveWorld`）時打開也正常（行囊已經是這樣做，照抄）。
- 吸血鬼被動要等心法大節點做好才有地方放；在那之前先送「吸血 +3% 的傳說佩」頂著。

## 6. 狀態
等使用者決定要不要拿掉「選英雄」。角色畫面改版（2-2）不刪任何功能，可以先做。
