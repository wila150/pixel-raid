# 15 手機介面：關閉、返回、切換（11/09，遊戲企劃 game）

使用者 11/09：「介面還是稍微有點問題，幫我看看角色那些。電腦可以用 Esc 關閉，手機不行且不方便。找找網路上遊戲的介面怎麼操作。」使用者也給了術語表（UI／UX、HUD、Title Bar、Bottom Navigation、Modal、CTA），以下照這套用語。

## 1. 現況（v5.3，手機橫向 844×390、直向 390×844 截圖）
介面分兩種做法，操作不一致：
| 介面 | 做法 | 怎麼關 |
|---|---|---|
| 行囊、角色、星盤、設定、聊天 | 覆蓋層 `#ov` | 點「空白處」（inv.js 的 click 判斷）、電腦 Esc／快捷鍵 |
| 技能、任務、排行 | 舊的 `.screen` | 最下面的按鈕（任務頁那顆被切在畫面外，要捲才看得到）；排行是「回到仙界」 |

問題：
1. **手機沒有一定找得到的關閉鍵**。覆蓋層在手機橫向幾乎佔滿整個畫面，沒有「空白處」可以點；能點的地方又被一長串「點到這些不算」的例外擋掉，玩家點了沒反應會以為壞掉。
2. **右上快捷列蓋住介面內容**：行囊右欄標題「工藝台」、角色分頁「外觀」被壓在快捷列底下。
3. **想換頁要先關再開**：看完行囊想看角色，要先找地方關掉，再點快捷鍵。
4. 技能、任務頁有白色的原生捲軸（跟深色風格不搭）、底部被切掉。
5. **直向**：頁面比畫面寬（出現左右捲動）；行囊要先捲過整個裝備圖＋武器組＋配點，才看得到背包格子。
6. Android 的「返回」手勢／按鍵現在沒用（按了可能直接離開遊戲或跳出全螢幕）。

## 2. 別的遊戲怎麼做（網路資料＋常見手遊）
- **關閉鍵固定在同一個角落**（通常右上），每個介面都一樣，玩家不用找。（creation.dev 的 Roblox UI 建議）
- **每個畫面都要有明確的返回／關閉**。（generalistprogrammer、Packt 手遊 UI 章節）
- 觸控裝置關畫面要點好幾下會讓玩家抱怨 → **按鈕要大**（至少 44px）。
- 一次只開一個介面，**用分頁切換**，不要疊好幾層。
- 暗黑破壞神：永生不朽是「手機優先」設計，介面元素做大；電腦版 Esc 關最上層視窗。
- 手機看物品說明不能靠滑鼠移上去 → 點一下出說明，用「從下面滑出的面板」或點旁邊關掉。
- 網頁做法：打開介面時塞一筆瀏覽紀錄（`history.pushState`），按 Android 返回時（`popstate`）只關介面、不離開遊戲。用 X 關的話要把那筆紀錄退掉，不然下次返回會怪怪的。

## 3. 提案
### 3-1 統一的「標題列」＋大 X（最重要）
所有介面（7 個全部，包括技能、任務、排行）最上面一條標題列：
```
[ 行囊 ]  行囊｜角色｜技能｜任務｜星盤｜聊天｜排行            [ ✕ ]
```
- **右上角固定一顆大 ✕**（觸控範圍至少 48×48），每個介面都在同一個位置。電腦一樣顯示，Esc 照舊能用。
- 打開介面時，右上的快捷列**變成這條標題列的分頁**：目前這頁亮起來，點別的直接換頁、不用先關（就是底部導覽列的概念，放在上面是因為下面有搖桿和技能鍵）。齒輪的位置換成 ✕。
- 這樣快捷列不會再蓋住內容（它本來就是標題列的一部分），介面內容從標題列下面開始排。
- 「點空白處關閉」保留當輔助，但不再是唯一方法。

### 3-2 Android 返回鍵
- 開任何介面 → 塞一筆瀏覽紀錄；按返回 → 關掉目前的介面（有子視窗就先關子視窗，例如確認框、物品說明）。
- 沒有介面時按返回：跳「要離開遊戲嗎？」確認，不要直接離開（以免誤觸丟掉未帶回的裝備）。
- iPhone 沒有返回鍵，靠 ✕ 和從左邊緣往右滑（可選，先不做）。

### 3-3 技能、任務、排行改成覆蓋層
跟行囊同一套 `#ov`（標題列、分頁、深色捲軸），拿掉白色原生捲軸和最下面的關閉按鈕。

### 3-4 直向排版
- 修掉左右捲動（找出比 390 寬的元素）。
- 行囊直向改成兩個分頁「裝備｜背包」，預設開背包（最常用），不用捲過裝備圖。
- 點物品：直向用「從下面滑出的說明面板」（物品數值＋穿上／賣掉按鈕），點面板外面或往下滑關掉；橫向維持右欄。

### 3-5 小東西
- 所有介面裡的按鈕高度至少 40px（＋／＋5 配點鈕現在偏小）。
- 介面打開／換頁動畫 0.2 秒內，不要拖。

## 4. 玩家體驗
不管開哪個介面，右上角一定有 ✕；想看別的頁直接點上面的分頁；Android 按返回就關掉，不會不小心跳出遊戲。電腦玩家完全照舊（Esc、快捷鍵都能用）。

## 5. 要改的檔案
- `js/inv.js`：`ovOpen`／`ovClose` 加標題列（共用函式 `ovHead(kind)`）、`#quick` 開介面時變分頁、`history.pushState`／`popstate`、行囊直向分頁、說明面板。
- `js/skills.js`、`js/quests.js`、`js/net.js`（`renderRank`）：改用 `ovOpen`。
- `js/char.js`：配合標題列、按鈕放大。
- `style.css`：標題列、✕、深色捲軸、直向修正。
- `js/world.js` `openHud`：技能／任務／排行改走覆蓋層。

## 6. 風險
- 返回鍵和瀏覽紀錄：iPhone Safari、LINE 內建瀏覽器、加入主畫面（全螢幕）三種情況行為不同，要各測一次；搞壞的話最壞是「按返回離開頁面」，要確保離開前有存檔（`cloudFlush` 已經有切走 App 時存）。
- 快捷列變分頁是玩家看得到的改變，但沒有拿掉任何功能，不用問使用者。
- 技能、任務頁搬到覆蓋層要注意原本的按鈕事件（`bindTri` 等）。

## 11. 手機攻擊鍵不能按住連打（11/09 使用者回報，**小修，最先做**）
- 原因（core.js 第 103–114 行）：手機技能鈕 `pointerdown` 只把動作放進 `padAct` 一次，每幀結束 `padAct.clear()`（main.js 74 行）→ **按一下＝打一下**，按住沒有效果。電腦按住會一直打，是因為 world.js 619 行看 `mouse.down`／`keys.has("j")`。
- 修法：新增 `padHeld`（Set），按下加入、`pointerup`／`pointercancel`／`pointerleave` 移除（建議用 `setPointerCapture`，手指稍微滑出按鈕也不會斷）；619 行加上 `padHeld.has("attack")`（跟 `mouse.down` 一樣看冷卻）。開介面（`ovOpen`）、切走 App（blur）、`inMenu` 時清空。
- Q 要不要按住連放：先不要（Q 耗真氣，按住會一直噴光真氣）；只做普攻。
- 順便：手機技能鈕現在有冷卻陰影（`.btn .cd`，由下往上的遮罩），第 8 節「確認冷卻」這條算已經有了；改成扇形轉圈放第二版。
- 驗收：手機（或 Chrome 手機模擬）按住攻擊鍵，攻速跟電腦按住滑鼠一樣；放開立刻停；按住時用搖桿走路照樣能打。
