# 58 行囊配色看不清楚（11/10，遊戲企劃 game；使用者：「背包的顏色配置看不太清楚」）

## 1. 企劃看截圖找到的問題（v9.8.2 截圖 844×390、390×844）
1. **直向的按鈕幾乎看不到字**：「行囊 30／30」「倉庫」、分頁（裝備／寶石／鑰匙…）、「一鍵出售／一鍵分解／全部送倉庫」是淺灰底＋淺色字。原因：`.ov button`（style.css:244）只設了字的顏色、沒設底色，`.b2` 裡的按鈕吃到瀏覽器預設的淺灰底，再配上 `--txt` 的淺米色字。橫向剛好被別的規則蓋過，所以只有直向特別嚴重。
2. **紫色、藍色那幾列，名字跟底色混在一起**：底色是用品質色調出來的漸層（`color-mix 16%`），紫字壓在紫底上、藍字壓在藍底上；紫、橘列的呼吸發光又讓底色一直變，更難看清楚。
3. **右邊「Lv54・T3」、戰力旁的小字太暗**：`--dim` #8a8070 在深紫底上對比不夠，字又只有 10px。
4. 停用的按鈕（`:disabled` opacity 0.4）在淺灰底上整顆糊掉。

## 2. 改法（只改顏色，版面不動）
- **按鈕**（`.ov .b2 button`）：底色 #241d2e、邊框 #5a4a38、字 #ece4d4。選中的（`.on`）改成金框、金字，底色 #3a2f1a。停用的不要用 opacity，改成字 #6f6878、邊框 #3a3442，底色不變。
- **清單每一列**：底色統一改成深色 #1b1622（不再用品質色漸層）。品質改用**左邊 4px 色條**加上邊框（品質色 55%）表示；呼吸發光只改邊框跟色條，底色不變。
- **名字的顏色**在深底上調亮一點：白 #f2f0f6、藍 #7cc4ff、紫 #cf9bff、橘 #ffa45c（只用在行囊和倉庫的清單，`RARITY` 不改）。
- **小字**：`.b2` 裡的 `--dim` 改成 #b0a48e，「Lv・T」字改成 11px。
- 詞綴那一行 #cfc4dc 維持不變。
- 裝備欄小格：有穿東西的格子，邊框用品質色 2px；空的格子「冠」「袍」字改用 #a89c8a。
- 對比目標：所有文字跟它的底色對比至少 4.5:1（白話：手機開低亮度也看得清楚）。

## 3. 要改的檔案
- `style.css`：`.ov .b2` 那一段，以及 1124–1148 行的直向、矮螢幕規則。
- `js/bag2.js`：`b2Row` 加左邊色條（用 `--c` 就好）。

## 4. 驗收
- 截圖 844×390、390×844、1280×720，四種品質各一列、選中的分頁、停用的按鈕都要看得清楚。
