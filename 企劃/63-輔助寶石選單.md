# 63 輔助寶石選單：分頁＋彈出視窗，不用一直往下滑（11/11，遊戲企劃 game；使用者：「輔助寶石那邊很麻煩，要滑到底下太多了，會不會是做下拉式或是分頁紅綠藍」）

## 1. 現況（tri.js 技能鏈 `pick`）
- 點技能鏈的空格 → 選單**接在那一列下面**展開：每顆寶石、每個等級各一顆大按鈕，按鈕裡有名字、類型、好處、代價好幾行；不能串的也全部列出來（灰色）。
- 寶石一多（19 種新寶石＋舊的，×5 個等級）就是好幾頁；E 列、身法列在下面，選單又更下面，要滑很久。3 合 1 也在最下面。

## 2. 提案（用分頁，不用下拉——手機下拉選單字小、看不到說明）
1. **彈出視窗**：點空格 → 跳一個視窗（橫向：畫面中間 80% 寬；直向：從下面滑上來，高 70%），不再接在列下面，不用往下滑找。上面寫「串到：萬劍（Q）第 2 格」＋✕。
2. **分頁**：**可以串**（預設）｜紅｜綠｜藍｜全部｜合成。
   - 「可以串」只列這一格現在串得上的（等級、標籤、互斥都過的）；紅綠藍＝照顏色，不能串的放最後、灰色、寫原因。
   - 記住上次選的分頁（`pr_gemTab`）。
3. **一種寶石一列**：同一種不同等級合成一列，顯示最高那級（例：「分裂 3 級 ×1　還有 1 級 ×4」），點開才選等級。
4. **列要短**：圖示＋名字＋等級＋**一行**好處（例：「投射分成 3 道」），點一下展開完整說明和代價＋「串上去」鈕；已經串在別招的寫「在 Q（萬劍）→ 搬過來」。
5. **合成分頁**：所有可以 3 合 1 的列在這裡，不再放在選單最下面。
6. 上面加小搜尋框（打「投射」「火」就篩），跟行囊一樣。

## 3. 玩家體驗
- 點空格 → 跳出視窗 → 預設只看得到能串的幾顆 → 點一下看說明 → 串上去。不用滑。

## 4. 要改的檔案
- tri.js：`pick` 那段改成彈窗（可以借 `.kfbox`／`.pt-sheet` 的樣式）＋分頁狀態 `gemTab`；`bindTri` 綁分頁、展開、搜尋；寶石合成按鈕搬過去。
- style.css：彈窗、分頁、短列。

## 5. 驗收（截圖）
