# 企劃_1.0完整化（v1.1，11/15，遊戲企劃 game）

> v1.1 修改摘要：解鎖表「星盤」從 Lv.30 改成一開始。星盤是傳送用的大地圖（`openStarMap`），不是養成系統，企劃 v1.0 寫錯了。

> 使用者指令一「遊戲完整度體檢」：從第一次打開到關掉再玩，列出 1.0 待補清單（最多 5 項，影響最大的排前面）。
> 依據：v9.34＋本機未上線的 79，用模擬器以新玩家身分實際玩（電腦 1280×720、手機 844×390），截圖在企劃 scratchpad `np/`，加上讀程式。
> 遵守 `企劃/README.md` 企劃五條鐵律：不改既有名稱和按鍵，只補流程。

## 0. 邊界條件（每項都要處理）
| 狀況 | 處理 |
|---|---|
| 無痕模式／儲存空間滿，存不了檔 | 不能默默失敗，要跳提示（見第 2 項） |
| 同一帳號兩台裝置都在玩 | 以「最後更新時間」比較，不能直接覆蓋（見第 2 項） |
| 上傳雲端時斷線 | 本機照存，標記「待上傳」，連回來再送 |
| 新角色在舊版補償程式跑之前就建立 | 新角色不吃任何「舊玩家補償」（見第 1 項） |
| 等級還沒到就點了鎖住的功能 | 顯示「Lv.X 開放」，不開空畫面 |
| 重複點擊「開始」「踏上仙途」 | 第一次點了就把按鈕變灰，避免建兩次角色 |

## 1. 新手前 3 分鐘：畫面中間太多字、送錯訊息（影響最大）
**看到的問題（截圖 pc_p3、ph_p2）：**
- 剛建好的 Lv.1 角色，一進場劍靈就說「**抗性改版**：舊的元素抗性變成全元素抗性一半…送你避雷丹材料」。這是 v6.8 給舊玩家的補償通知。原因：`resist.js resMigrate` 只看 `save.resMig`，新存檔沒有這個標記，所以新角色也會跑一次（還多拿 700 靈石和材料）。驗收 79 時用新存檔又看到劍靈說「英雄系統改版（選英雄拿掉了）」，所以不只一個補償有這個問題。
- 同一時間，畫面中間疊了兩層字：新手提示「新手 1/6 用 WASD 走走看」跟劍靈對話框（「得到 2 顆輔助寶石…還有 5 句」）疊在一起，蓋住角色。
- 出生點正好是 77 新做的秘境台、倉庫箱、鐵砧旁邊，加上秘境使者、丹師的大字名牌，一共 5 個大字。「倉庫箱」三個字壓在角色身上，「秘境使者」壓在左上頭像上。Lv.1 根本用不到這些。

**規則：**
- If 建立新角色 Then `blankSave()` 把所有「舊版補償」旗標（`resMig` 等所有 `*Mig`、`hv`、`jv`…）都設成已完成。工程師要全部搜一遍 `setInterval(xxMigrate` 和 `if (!save.xxx)` 這類一次性補償。
- If 新手教學還沒完成（`save.w.tut < TUT.length`）Then 劍靈只說新手台詞；改版公告、補償 `notice` 先排隊，教學完成後再說。
- If 新手提示正在顯示 Then 劍靈對話框不能出現在畫面中間，要改到左下角聊天上方，或等提示換下一步再出現。**同一時間畫面中間最多一個提示。**
- If 玩家 Lv < 10 Then 秘境台、倉庫箱、鐵砧的名牌只在角色 120 單位內才顯示，字縮成 NPC 名字大小。NPC 名牌（`drawCamps`）不能畫在頭像和任務欄上面（HUD 那一區不畫世界上的字）。
- If 出生點離秘境台 < 80 單位 Then 新角色出生點往南移到廣場空地，第一眼要先看到「出城往北」的路。

## 2. 存檔安全：可能悄悄丟進度
**看到的問題（讀程式）：**
- `auth.js onLogin`：登入時只要雲端有存檔，就**直接蓋掉**這台裝置的存檔，沒有比較哪邊比較新。例如在手機玩了 20 分鐘沒登入、或上傳還沒送出就關掉，再登入時這 20 分鐘就沒了。
- `cloudFlush` 上傳失敗用 `.catch(() => {})` 吞掉，玩家不知道沒存到。
- `save.js writeSave`：存不了（無痕模式）也是默默略過，玩家關掉就全沒了。

**規則：**
- 每次 `writeSave` 都在 `save.ts` 記下現在的時間。
- If 登入時雲端 `save.ts` > 本機 `save.ts` Then 用雲端存檔。
- If 本機比較新 Then 用本機存檔，並馬上上傳。
- If 兩邊都有進度、而且等級或時間差很多 Then 跳出選擇框：「這台：Lv.X、Y 分鐘前 ／ 雲端：Lv.Z、W 分鐘前」，讓玩家選一個；**被換掉的那份存成備份**（`localStorage` 另一個 key），可以在設定裡還原一次。
- If 上傳失敗 Then 右上角顯示小雲朵＋驚嘆號「還沒存到雲端」，每 30 秒重試；成功後消失。
- If `localStorage` 寫入失敗 Then 跳一次提示「這個瀏覽器不能存檔（無痕模式？），關掉就會不見，建議登入帳號」。
- If 沒有登入、而且玩到 Lv.10 Then 劍靈說一次「登入帳號就能換手機繼續玩、不怕清掉瀏覽器」，附一顆「登入」按鈕。

## 3. 按鈕按等級解鎖（介面大器、不瑣碎）
**看到的問題：** Lv.1 電腦版上面 7 顆（行囊、角色、技能、天賦、鐵匠、秘境、星盤）＋右邊 6 顆（卡片、任務、手冊、排行、祭壇、設定），全部一開始就亮。新手不知道先點哪個，點進去也是空的（例如星盤、秘境）。手機技能弧上有 4 顆空的「＋」，看不出來是「還沒解鎖」還是「要自己放」；電腦版同一格會寫 Lv.5、Lv.10，手機沒有。

**規則（解鎖表，工程師直接讀）：**
```csv
按鈕,開放條件,開放時劍靈台詞
行囊,一開始,
技能,一開始,
設定,一開始,
任務,一開始,
角色,Lv.3,
天賦,Lv.5,天賦點開了，點一點變強
鐵匠,Lv.8,
手冊,Lv.8,
卡片,第一次拿到卡片,
秘境,Lv.20 或拿到第一把鑰匙,
星盤,一開始,
排行,Lv.15,
祭壇,第一次看到祭壇,
```
- If 還沒開放 Then 按鈕不顯示；手機 ☰ 選單裡的格子顯示灰色＋「Lv.X」，點了只說「Lv.X 開放」。
- If 剛開放 Then 那顆按鈕閃 3 秒＋紅點，劍靈說台詞（有寫的才說）。
- If 手機技能格還沒解鎖 Then 跟電腦版一樣顯示「Lv.5」，不是「＋」；解鎖了但還沒放招才顯示「＋」。
- 舊角色（等級已經超過）全部直接開放，不閃、不說。
- 這只是**隱藏**按鈕，不改任何按鈕的名字和位置（鐵律 1）。

## 4. 手機小地方
**看到的問題：**
- 護身法術按鈕在手機上寫「時間」，「時間回溯」被切掉，看不懂。
- 新手提示寫「按住畫面左半邊拖曳」，但畫面上沒有搖桿圖示，新手看不到可以按哪裡。

**規則：**
- If 護身法術名字 > 2 個字 Then 手機按鈕顯示 2 個字的簡稱（時間回溯→回溯、化身霧氣→化霧、血霧無敵→血霧），長按顯示全名。
- If 手機橫向（高 ≤ 430）開行囊 Then 裝備格改成每列 6 格（現在 8 格，圖示只有約 24px），圖示至少 36px；升級箭頭「↑」移到格子右上角外框上，不要壓在圖上。（v9.38 換新圖示後發現）
- If 新手第 1 步（走路）Then 左下角畫一個半透明的搖桿圈＋手指動畫，走過 3 秒後消失。

## 5. 核心循環要量過才知道（交給工程師跑 bot）
這次只看了前 3 分鐘，「打怪→變強→挑戰更難」中間有沒有卡關或無聊的地方，要用數字看：
- bot 從 Lv.1 一般裝跑到 Lv.70，記錄：每 10 級花幾分鐘、每次升級後擊殺速度有沒有變快、哪一段死最多次、哪一段連續 5 分鐘以上沒有新裝備。
- If 某 10 級花的時間 > 前一段的 2 倍 Then 標成卡關點。
- If 連續 10 分鐘以上沒拿到比身上好的裝備 Then 標成無聊點。
- 結果回報企劃，企劃再寫成指令二（數值優化）的規格。
